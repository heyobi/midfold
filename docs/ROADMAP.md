# Midfold roadmap

v1 is one focused game: pump the hinge to fly. Ideas that need a real iPhone Duo to tune:

- Pump feel: tune `PumpDetector` (minimum depth, hysteresis, strength curve) from TestFlight feedback on real hardware.
- A resting-angle nuance (a slight glide when held more open), only if it keeps "pump to fly" clear.
- Cosmetic paper packs for Kip (one-time purchases), more worlds.

Other ideas from the same brainstorm (fold-simulator mini-games, a fruit-slicing game with a world-locked background, face-to-face duels) are separate future apps, not features of Midfold.
